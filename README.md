One original line: a funny name for a band made of robots, plus a few words on the band's hit song. The band is named after the problem, not a robot part — the Wi-Fi Dead Zones. Its hit single streamed 40 million times, all of it from the hallway, because the band is famous but never actually makes it into the room.

The line is 111 characters, inside the competition's 1–200 character, single-line gate. Running `main.py` validates it first (not blank, one line only, length inside the gate) and then writes it verbatim to `/output/entry.txt` and prints it.
